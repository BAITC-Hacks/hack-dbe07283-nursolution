# hack-dbe07283-nursolution
Hackathon team repository for NurSolution

## Подбор подрядчиков

Python 3.10+. Исходный CSV загружается относительно `smart_matcher.py`.

```powershell
python -m pip install -r requirements.txt
$env:OPENAI_API_KEY = "ваш API-ключ"
python smart_matcher.py
```

Без API доступны демо и тесты matcher, использующие только стандартную библиотеку:

```powershell
python smart_matcher.py --offline
python -m unittest test_smart_matcher -v
```

```python
from smart_matcher import EventMatcher

matcher = EventMatcher()
result = matcher.match(
    city="Алматы", date="2026-09-26", event_type="корпоратив",
    category="Ведущий", budget=1_000_000, language="русский",
    duration=4,  # необязательно; часы
)
print(result["message"])
for card in result["cards"]:
    print(card["anon_name"], card["explanation"])
```

Результат — JSON-совместимый словарь. `status` различает `matched`,
`no_category_in_city` и `no_matches`; `message` объясняет пустую или неполную
выдачу. `scope_count` — число профилей в городе и категории; `eligible_count` —
число прошедших все условия до ограничения TOP-3.

Четыре этапа:

1. CSV и строгие фильтры Python: город → категория → бюджет → дата → формат →
   язык → опциональная длительность. `rejection_counts` учитывает только первую
   причину отказа каждого профиля. Сумма счётчиков плюс `eligible_count` равна
   `total_profiles`. Неизвестная длительность при запросе часов исключается
   отдельно (`duration_unknown`). Регистр и внешние пробелы не влияют на поиск.
2. Пустые выдачи возвращаются до создания API-клиента. Аналитика строится только
   по профилям выбранных города и категории. `suggestions` содержит проверенные
   изменения одного условия: минимальный достаточный бюджет, ближайшая следующая
   дата в пределах 14 дней, альтернативный формат/язык или меньшая длительность.
   Каждый совет проходит все остальные фильтры; включает `field`, `value`,
   `candidate_count`, `candidate_ids`, `message`. Изменения не применяются автоматически.
   Если одиночного изменения недостаточно, ответ прямо сообщает об этом.
3. Сортировка по разнице с бюджетом, совпадению языка, строковому `id`.
   При строгом языковом фильтре второй ключ одинаков у всех кандидатов.
4. Один запрос для TOP-3 к `gpt-4o-mini`, `temperature=0.0`; модель выбирает полезную
   для заказа дословную цитату из подготовленных фрагментов описания. Python проверяет
   принадлежность цитаты профилю и формирует объяснение из цитаты и проверенных
   условий заказа. Свободный текст модели не выводится: это исключает добавление
   неподтверждённых цен, достижений и обещаний бронирования. Результат сопоставляется
   по `id` и не влияет на порядок. Используется
   [Chat Completions API](https://platform.openai.com/docs/api-reference/chat/create).

Нет ключа, ошибка API или некорректный ответ — карточки сохраняются с объяснениями
на Python, полем `warning` и `explanation_source="python"`. При ошибке цитаты или
пропуске одного профиля заменяется только его объяснение; неизвестные/дублирующиеся
id делают ответ целиком некорректным. В проверенном API-ответе источник — `openai`:
модель выбрала цитату, итоговый текст собран Python. Поле `evidence` содержит
`field="description"` и `quote`, либо `null`, если подходящего фрагмента нет.
Офлайн-выбор предпочитает отличающие профиль фрагменты и числовые факты; рекламные
клише исключаются. Сведения из описаний атрибутируются подрядчику: проверяется
совпадение с CSV, а не достоверность заявлений в реальном мире. Если в данных нет
различающих фактов, система их не придумывает. Цена «от» не является окончательной сметой; отсутствие
даты в списке занятости не подтверждает бронирование.

API настроен на таймаут 7 секунд без автоматических повторов. Это ограничивает
обычное ожидание, но не гарантирует общий SLA 10 секунд при всех сетевых сбоях;
боевую задержку нужно измерить с действующим ключом. Порядок карточек полностью
детерминирован; выбор цитаты LLM при temperature=0 может меняться. Полезность
выбранных цитат и задержку нужно дополнительно оценить с действующим API-ключом.

Тесты покрывают все фильтры, стабильность порядка, отсутствие API-вызовов при
пустой выдаче, повторную проверку советов, ограничения горизонта дат, неизвестную
длительность, выдуманные цитаты, дополнительные утверждения модели и частичный
переход на объяснения Python.

## HTTP API (FastAPI)

Веб-интерфейс уже подключён к API и доступен по адресу
[http://127.0.0.1:8000](http://127.0.0.1:8000). Один сервер обслуживает и страницу,
и подбор: отдельный запуск Node.js и сборка фронтенда не нужны.

Создать окружение и запустить сервер из корня проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
$env:MATCHER_USE_LLM = "false"  # локальное демо без OpenAI
.\.venv\Scripts\python.exe -m uvicorn api:app --reload --host 127.0.0.1 --port 8000
```

Для объяснений с LLM задайте `MATCHER_USE_LLM=true` и `OPENAI_API_KEY` в окружении
сервера либо в `.env` (образец — `.env.example`). Ключ не передаётся браузером.
`MATCHER_CSV_PATH` позволяет указать другой CSV. Каталог загружается один раз при
старте каждого процесса; при отсутствии или повреждении файла сервер не запускается.
Чтобы перечитать изменённый CSV, перезапустите сервер.

- `GET /health` — готовность сервиса и число загруженных профилей (не проверяет OpenAI).
- `GET /catalog` — города, категории, форматы и языки из загруженного CSV для формы.
- `POST /match` — подбор и аналитика.
- [Swagger UI](http://127.0.0.1:8000/docs) — интерактивные запросы и схемы.
- [OpenAPI JSON](http://127.0.0.1:8000/openapi.json) — контракт для фронтенда.

Тело `POST /match`:

```json
{
  "city": "Алматы",
  "date": "2026-09-26",
  "event_type": "корпоратив",
  "category": "Ведущий",
  "budget": 1000000,
  "language": "русский",
  "duration": 4
}
```

`language` и `duration` можно опустить или передать `null`. Бюджет и часы должны
быть JSON-числами, дата — существующей календарной датой в формате `YYYY-MM-DD`.
Неизвестные поля, пустые строки, отрицательный бюджет и неположительная длительность
отклоняются. Числовые строки и логические значения не преобразуются в числа.

Все три бизнес-исхода (`matched`, `no_category_in_city`, `no_matches`) возвращают
HTTP 200 и одну схему `MatchResponse`. `cards` и `suggestions` всегда списки,
`warning` — строка либо `null`. Пустой подбор не является ошибкой сервера.
При ошибке ввода HTTP 422 содержит указание полей, например:

```json
{
  "error": {
    "code": "validation_error",
    "message": "Проверьте параметры запроса.",
    "fields": [
      {"field": "budget", "message": "Значение должно быть неотрицательным.", "type": "greater_than_equal"}
    ]
  }
}
```

Неожиданная внутренняя ошибка возвращает HTTP 500 с `error.code="internal_error"`,
без трассировки и служебных данных. Недоступность OpenAI обрабатывается matcher:
HTTP 200 с карточками Python и предупреждением.

Пример вызова из фронтенда:

```javascript
const response = await fetch("http://127.0.0.1:8000/match", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify(order),
});
const result = await response.json();
if (!response.ok) throw new Error(result.error.message);
// result.status определяет состояние экрана; result.cards — карточки.
// При выборе подсказки отправьте {...order, [suggestion.field]: suggestion.value}.
```

По умолчанию CORS разрешает `localhost` и `127.0.0.1` на портах 5173 и 3000.
Для другого адреса задайте `CORS_ORIGINS` списком origins через запятую (без путей).
Синхронный подбор выполняется в пуле потоков FastAPI: ожидание LLM не блокирует
цикл обработки запросов. Общий дедлайн HTTP-запроса пока не реализован; действует
описанный выше таймаут SDK.

Для полного набора тестов API и matcher:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest -v
```

API использует [lifespan FastAPI](https://fastapi.tiangolo.com/advanced/events/) для
загрузки каталога и закрытия SDK-клиента, а
[response models](https://fastapi.tiangolo.com/tutorial/response-model/) — для
проверки и документирования ответов. Тесты выполняются без внешних API-вызовов.

## Интерфейс

Исходники находятся в `frontend/`: `index.html`, `styles.css`, `app.js`.
Страница адаптирована для компьютера и телефона, работает с клавиатуры и учитывает
настройку уменьшения анимации. Шрифты системные; внешние CDN не требуются.

При открытии показывается подборка по демонстрационным параметрам формы
(Алматы, 26 сентября 2026, корпоратив, ведущий, бюджет 1 млн ₸). При включённой
LLM это один реальный запрос к OpenAI; для демонстрации без расходов используйте
`MATCHER_USE_LLM=false`. После изменения условий нажмите «Подобрать людей».
Старые результаты помечаются, а устаревшие ответы не перезаписывают новый поиск.

В пустой выдаче доступны проверенные подсказки: кнопка изменяет соответствующее
поле и сразу повторяет подбор. Отсутствующая категория, отсутствие совпадений,
загрузка, ошибки ввода и ошибки соединения имеют отдельные состояния.
Клиент прерывает ожидание через 12 секунд и предлагает повторить запрос; это
не заменяет серверный дедлайн и не останавливает уже выполняющийся вызов OpenAI.
